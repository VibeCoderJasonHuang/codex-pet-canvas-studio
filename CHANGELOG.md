# Changelog

## 0.1.0

- Added arbitrary character image upload and background removal.
- Added the Mallow base mascot and one optional armor template.
- Added pixel-by-pixel character drawing.
- Added independent custom accessory drawing.
- Added timeline editing for all nine Codex companion states.
- Added per-action FPS and loop controls.
- Added Canvas-based frame preview to avoid neighboring-frame artifacts.
- Added native Codex ZIP export and local installation.
- Added GitHub CI, release packaging, and portable Windows build scripts.
